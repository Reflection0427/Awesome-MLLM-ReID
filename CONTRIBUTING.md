# Contributing

Contributions are welcome through issues and pull requests.

For a new paper, verify that it belongs to the MLLM/LVLM ReID scope, is not a duplicate, and has stable publication metadata. Every formal paper entry must include one original author-created Figure cropped from a pinned official PDF. See [the paper tracker guide](docs/PAPER_TRACKER.md) for the required metadata and review commands.

Automated candidate pull requests are queues for human review, not additions to the formal collection. Do not merge their candidates directly into README.
